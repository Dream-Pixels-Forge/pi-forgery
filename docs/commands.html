Commands

All commands are prefixed with /forgery.

CommandEffect
/forgeryOpen the full-screen dashboard (Activity view)
/forgery statusPrint a compact config + activity summary
/forgery agentsList recorded one-shot agents
/forgery log <id>Show one agent's transcript
/forgery stop <id>Stop one running agent
/forgery settingsRead-only host-call + agent runner config
/forgery image <path>Display an image inline in the terminal (Kitty graphics protocol)
/forgery video <path>Play a video inline in the terminal (Kitty graphics protocol, ffmpeg frame extraction)
$ /forgery image screenshots/homepage.png
[Image: screenshots/homepage.png [image/png] 1600×1000]
$ /forgery video recordings/qa-run.mp4
video kitty recordings/qa-run.mp4 (24 frames)
$ /forgery status
forgery status · host calls 14 · pi binary pi · concurrency 4
