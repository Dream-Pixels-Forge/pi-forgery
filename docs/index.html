Capabilities

A focused, auditable extension that keeps the best parts of a programmable tool runtime.

forgery_exec

One flat tool the LLM calls with a TypeScript program composing Pi core tools and one-shot agents. Independent calls run in parallel; each call is schema-validated before execution.

forgery_exec({ code: "..." })

One-shot agents

agents.run spawns a child Pi session in a subprocess and returns text + usage. Bounded concurrency, timeouts, and cost budgets.

agents.run({ task: "..." })

Model routing

agents.route recommends the cheapest model that historically completes this kind of task, based on per-model outcome history.

agents.route({ task: "..." })

Workflow chains

workflow.chain composes pipelines sequentially, threading each step's artifact into the next with pause/abort gates.

workflow.chain({ steps: [...] })

Activity distill

activity.distill mines completed runs for repeated host-call sequences and proposes them as reusable presets.

activity.distill({ minOccurrences: 2 })

Budget circuit breaker

Mid-run cost enforcement: warn at 80% of max cost, hard-stop at 100%. Surfaces as a priority-0 footer segment.

cost.budget({ maxCostPerRun: 1.00 })

Durable journal

workflow.resume replays completed phases from `.pi/forgery/journal/` so long chains survive a Pi restart.

workflow.resume({ chainId: "..." })

Status line & footer

Custom footer showing git branch, context tokens/percent, model, active run metrics, and budget alerts.

ctx.ui.setStatus("forgery", ...)

Activity widget

Above-editor box that auto-hides when idle. Focus + expand reveals an inline activity transcript.

ctrl+alt+e

Terminal media

Images and video inline via Kitty graphics protocol (Ghostty, Kitty, Warp, WezTerm, iTerm2). Text fallback on unsupported terminals.

pi.showImage({ path: "screenshot.png" })

Install & Develop

$ pi install /absolute/path/to/pi-forgery
Extension loaded: forgery_exec, /forgery, widget, footer
$ pi -e /absolute/path/to/pi-forgery
One development run

Install

The entry is extensions/forgery/index.ts, declared in package.json → pi.extensions. Pi's loader transpiles TS directly — no build step required.

Develop

Typecheck and tests run against the sibling Pi host's @earendil-works/* type declarations. No network, no native dependencies.

npm run typecheck
npm test
