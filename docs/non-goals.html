Non-Goals

These are parts pi-forgery deliberately does NOT do — they add large native dependencies and startup cost without helping the "programmable tool + live status" goal.

No durable-residency actors

No actor mesh, topics, councils, or recursion graphs.

No speculative machinery

No speculative PTC, prompt-cache warming, entropy/proof certifiers, Jev, or Bend verified policy kernels.

No Python/Monty kernel

TypeScript only; a Python kernel is a follow-up opt-in flag.

No separate provider registry or MCP bridge

Single pi host.
