Usage

Usage

You ask in plain language. Pi writes one forgery_exec program that composes the required tools and agents:

// A forgery_exec program the model can author
const [manifest, sources] = await Promise.all([
  pi.read({ path: "package.json" }),
  pi.find({ pattern: "**/*.ts", path: "src" }),
]);
return {
  package: JSON.parse(manifest).name,
  sourceCount: sources.split("\n").filter(Boolean).length,
};

Independent calls run in parallel. agents.run spawns one-shot Pi subprocesses for tasks that need their own context.

Terminal Media Display

Images

pi.showImage draws one image file inline in the terminal via the Kitty graphics protocol (Ghostty, Kitty, Warp, WezTerm, iTerm2). Supported terminals render the image directly; others show a text path fallback. Non-PNG images are transcoded to PNG automatically.

await pi.showImage({ path: "screenshot.png", maxWidthCells: 100 });

Multiple images

pi.showImages displays several image files in sequence.

await pi.showImages({
  paths: ["a.png", "b.png", "c.png"],
  maxWidthCells: 60,
});

Video

pi.showVideo plays a video file inline via the Kitty graphics protocol. It uses ffmpeg to extract frames at up to 12 fps and draws them as an animation.

await pi.showVideo({ path: "recording.mp4", maxWidthCells: 100 });
$ /forgery image screenshots/homepage.png
[Image: screenshots/homepage.png [image/png] 1600×1000]
$ /forgery video recordings/qa-run.mp4
video kitty recordings/qa-run.mp4 (24 frames)

Terminals: Works in any terminal supporting the Kitty graphics protocol (Ghostty, Kitty, Warp, WezTerm, iTerm2). When the terminal cannot render inline media, a text fallback shows the file path, MIME type, and dimensions instead.
